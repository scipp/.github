# Contributing

This is the default contributing guide for repositories in the scipp organization that do not have their own.

## AI-generated contributions

We are not interested in pull requests generated by AI agents.
Reviewing them costs us more than running an agent ourselves.
We make an exception only if you contributed significant insight that your agent could not have provided, for example from using the code in your own work.

If you found a bug, please open an issue in the repository with a minimal reproducer instead.
